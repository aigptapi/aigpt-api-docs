# Privacy Policy

## Data Collection
We collect only the minimum data necessary to provide our API service: API requests (prompts) and responses (completions), timestamps, and token usage for billing.

## Data Usage
- Prompts and completions are processed solely to deliver the API service.
- We do **not** use user data to train models.
- We do **not** sell or share user data with third parties.

Logs are retained for a maximum of 30 days for debugging and billing purposes, then automatically deleted. Users may request immediate deletion by emailing wzh786008887@outlook.com.
